# 境阅 · 风景漫游

境阅是一页安静浏览自然风景的轻量网页。选择一处远方，让视线先抵达。

## 页面内容

- 全屏风景首页
- 阿尔卑斯湖与挪威峡湾目的地切换
- 适配桌面和手机屏幕

## 本地预览

在项目根目录运行：

```bash
cd jingyue-product-page
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。也可以直接用浏览器打开 `jingyue-product-page/index.html`。

## 项目文件

- `jingyue-product-page/index.html`：页面结构、样式与交互
- `jingyue-product-page/assets/`：风景图片
